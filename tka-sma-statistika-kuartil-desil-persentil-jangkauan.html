Kuartil: Membagi Data Menjadi Empat

Median membelah data menjadi dua; kuartil memperhalusnya menjadi empat bagian sama banyak — inilah "ukuran letak" pertama yang wajib kamu kuasai.

Kuartil adalah nilai-nilai yang membagi data terurut menjadi 4 bagian sama banyak. Q1 (kuartil bawah): 25% data bernilai ≤ Q1. Q2: tepat sama dengan median. Q3 (kuartil atas): 75% data bernilai ≤ Q3. Jarak Q1–Q3 menampung "50% data tengah" — ide inilah yang nanti menjadi jangkauan antarkuartil di Bab 4.

Q1 · 25% Q2 · 50% Q3 · 75%

Q2 = median: dua ide berbeda, satu titik yang sama.

Letak Qi = i(n + 1) : 4   untuk i = 1, 2, 3 Banyak data = n. Letak bulat → kuartil = data pada posisi itu. Letak pecahan → interpolasi antara dua data bertetangga: Q = xk + t × (xk+1 − xk), dengan t = bagian pecahannya.

n ganjil — sering letaknya bulat

Data 6, 7, 7, 8, 8, 8, 9, 9, 10 (urut, n = 9).
Letak Q1 = 10 : 4 = 2,5 → antara data ke-2 dan ke-3: Q1 = 7 + 0,5×(7 − 7) = 7.
Letak Q2 = 10 : 2 = 5 → data ke-5 = 8 (= median ✓).
Letak Q3 = 3(10) : 4 = 7,5 → Q3 = 9 + 0,5×(9 − 9) = 9.

n genap — interpolasi murni

Data 4, 5, 6, 7, 8, 9, 10, 12 (n = 8).
Letak Q1 = 9 : 4 = 2,25 → 5 + 0,25×(6 − 5) = 5,25.
Letak Q2 = 9 : 2 = 4,5 → (7 + 8) : 2 = 7,5.
Letak Q3 = 27 : 4 = 6,75 → 9 + 0,75×(10 − 9) = 9,75.

Catatan konvensi: di buku sekolah dan soal TKA, letak kuartil data tunggal memakai (n + 1) — bukan n. Perangkat lunak (Excel, kalkulator statistik) memakai konvensi lain sehingga hasilnya bisa selisih kecil; ikuti konvensi i(n+1):4 saat ujian. Ingat pula: Q2 selalu identik dengan median — kalau soal memberi median, kamu otomatis punya Q2.

Kuartil Data Kelompok

Pada tabel distribusi frekuensi, posisi kuartil dicari lewat frekuensi kumulatif, lalu diinterpolasi di dalam kelasnya — persis mesin median, hanya titik potongnya berubah.

Langkah 1: hitung posisi data ke–i·n : 4. Langkah 2: cari kelas kuartil — kelas pertama yang memenuhi F < i·n:4 ≤ F + f (F = kumulatif sebelum kelas itu). Langkah 3: interpolasi di dalam kelas.
Qi = Tb + ( (i·n : 4 − F) : f ) × c Tb = tepi bawah kelas kuartil (batas bawah − 0,5) · F = frekuensi kumulatif sebelum kelas kuartil · f = frekuensi kelas kuartil · c = panjang kelas. Pecahan (i·n:4 − F) : f = "seberapa jauh kita masuk ke kelas".

Kenapa hasilnya "pas" di tepi kelas? Di contoh ini posisi jatuh tepat di batas kumulatif (10 = 3 + 7), artinya data terakhir kelas itu adalah kuartilnya — rumus memberi tepi atas kelas kuartil. Wajar dan konsisten.
Checklist anti-salah: (1) Kelas kuartil dicari lewat kumulatif, bukan frekuensi tunggal. (2) F = kumulatif sebelum kelas kuartil. (3) Tb selalu berakhiran ,5 (mis. 50,5), bukan batas tulisannya (51). (4) c = batas atas − batas bawah + 1: kelas 41–50 → c = 10, bukan 9. (5) Jangan lupa mengalikan pecahan dengan c.

Desil: Membagi Data Menjadi Sepuluh

Kalau kuartil memotong di setiap 25%, desil memotong di setiap kelipatan 10% — sembilan titik potong: D1 sampai D9.

Desil Di (i = 1, …, 9) adalah nilai yang membagi data terurut menjadi 10 bagian sama banyak: i × 10% data bernilai ≤ Di. Tiga yang paling sering dipakai: D1 (batas 10% terbawah), D5 (= median = Q2), dan D9 (batas 10% teratas).

Letak Di = i(n + 1) : 10   untuk i = 1, 2, …, 9 Mesin yang sama dengan kuartil — pembaginya kini 10. Letak pecahan tetap diinterpolasi: D = xk + t × (xk+1 − xk).

Contoh n = 9

Data 5, 6, 6, 7, 8, 8, 9, 10, 12 (urut).
Letak Di = i(10) : 10 = i — semua desil tepat di data ke-i!
D3 = data ke-3 = 6; D7 = data ke-7 = 9; D5 = data ke-5 = 8 = median ✓.

Interpretasi & pakem soal cerita

"10% teratas" → batasnya D9; "10% terbawah" → batasnya D1; "30% teratas" → batasnya D7 (karena 100% − 30% = 70%).
D9 − D1 = jangkauan antardesil: merentang 80% data tengah.

Syarat letak ≤ n. Untuk n kecil, desil besar bisa "keluar dari jangkauan": dengan n = 8, letak D9 = 9(9) : 10 = 8,1 > 8, jadi D9 tidak terdefinisi (butuh minimal n = 9). Semakin besar i, semakin besar n minimum yang dibutuhkan — kalkulator di bawah akan memperingatkanmu saat itu terjadi.

Desil Data Kelompok

Rumus interpolasi yang sama dengan kuartil — pembilang posisinya kini i·n : 10.

Di = Tb + ( (i·n : 10 − F) : f ) × c Tb = tepi bawah kelas desil · F = kumulatif sebelum kelas desil · f = frekuensi kelas desil · c = panjang kelas. Kelas desil: kelas pertama dengan F < i·n:10 ≤ F + f.
Contoh. Pengeluaran harian 40 siswa (dalam ribuan rupiah): 40–49 (f = 3), 50–59 (7), 60–69 (12), 70–79 (10), 80–89 (6), 90–99 (2). Kumulatif: 3, 10, 22, 32, 38, 40.
D4: pos = 4 × 40 : 10 = 16 → kelas 60–69 (10 < 16 ≤ 22) → D4 = 59,5 + ((16 − 10) : 12) × 10 = 59,5 + 5 = 64,5.
D8: pos = 32 → kelas 70–79 (22 < 32 ≤ 32) → D8 = 69,5 + ((32 − 22) : 10) × 10 = 69,5 + 10 = 79,5.

Persentil

  • Persentil membagi data terurut menjadi 100 bagian: P1 sampai P99

  • Data kelompok: Pi = Tb + ((i·n : 100 − F) : f) × c

  • Aplikasi: skor tes, kartu pertumbuhan anak, cut-off PPDB, "top 1%"

Persentil: Skala Seratus

Skor tes nasional, kartu pertumbuhan anak, "top 1% terkaya" — semuanya berbahasa persentil. Ini kuantil paling halus; kuartil dan desil hanyalah persentil tertentu.

Persentil Pi (i = 1, …, 99) membagi data terurut menjadi 100 bagian sama banyak: i% data bernilai ≤ Pi. Jika skor Bima setara P85, artinya Bima mengalahkan sekitar 85% peserta — kedudukan relatif, bukan nilai mentah.

Mesin interpolasi yang sama — pembilang posisinya kini i·n : 100.

Contoh. Tinggi badan 40 siswa (cm): 146–150 (f = 2), 151–155 (6), 156–160 (12), 161–165 (10), 166–170 (8), 171–175 (2). Kumulatif: 2, 8, 20, 30, 38, 40; c = 5.

BAB 4

Jangkauan

  • Ukuran penyebaran: seberapa menyebar data di sekitar pusatnya
  • Jangkauan data tunggal: J = maks − min; data kelompok: tepi atas akhir − tepi bawah awal
  • Jangkauan antarkuartil H = Q3 − Q1 dan simpangan kuartil Qd = H : 2
  • Sifat transformasi: y = b·x + a → semua jangkauan dikali b, konstanta a tak berefek
  • Boxplot, pagar 1,5×H, dan uji ketahanan terhadap outlier
  • Lab interaktif: studio boxplot + kalkulator sebaran data kelompok
  • 10 soal HOTS berpembahasan

Jangkauan (Range)

Ukuran pemusatan menjawab "di mana pusatnya?" — jangkauan menjawab "seberapa menyebar isinya?". Dua kelompok data bisa berpusat sama namun sangat berbeda kerapianya.

Kelas A dan kelas B sama-sama berrata-rata 75 — tetapi nilai A tersebar 40 sampai 100 sedangkan B hanya 65 sampai 85. Jangkauan adalah ukuran penyebaran paling sederhana: selisih dua nilai ujung. Jangkauan kecil → data rapat (homogen); jangkauan besar → data menyebar (heterogen).
Data tunggal: J = data terbesar − data terkecil Contoh: 8, 5, 9, 7, 6, 10, 4 → urutkan → 4, 5, 6, 7, 8, 9, 10 → J = 10 − 4 = 6. Urutkan dulu agar ujungnya tak keliru!
Data kelompok: J = tepi atas kelas terakhir − tepi bawah kelas pertama Contoh: 31–40 (5), 41–50 (8), 51–60 (12), 61–70 (9), 71–80 (6) → J = 80,5 − 30,5 = 50. Kelas 31–40 menampung data hingga 40,5 dan kelas 71–80 hingga 80,5 — gunakan tepi kelas, bukan batas tulisannya (yang memberi 49, kurang 1).
Sifat transformasi — jika setiap data diubah menjadi b·x + a (b > 0): Jangkauan baru = b × jangkauan lama. Menambah konstanta a tidak mengubah jangkauan (semua data bergeser bersama). Contoh: J = 6 → semua data dikali 3 lalu ditambah 2 → J' = 3 × 6 = 18.
Kelemahan fatal jangkauan: ia hanya melihat dua ujung data. Satu nilai ekstrem bisa melipatgandakannya, sementara 98% data lain tak tersentuh. Karena itu statistikawan memakai ukuran yang lebih stabil — kenalan dengan H dan Qd di halaman berikutnya.

Jangkauan Antarkuartil & Simpangan Kuartil

Alih-alih seluruh data, ukur sebaran 50% data tengah — kuartil otomatis menyingkirkan gangguan di ujung.

Jangkauan antarkuartil (interquartile range) H = Q3 − Q1: panjang "kotak" yang menampung 50% data tengah. Simpangan kuartil (semi antarkuartil) Qd = H : 2: setengahnya, dipakai sebagai ukuran simpangan data tengah. H kecil → bagian tengah data homogen.
H = Q3 − Q1     Qd = (Q3 − Q1) : 2 = H : 2 Hitung Q1 dan Q3 dulu (data tunggal: letak i(n+1):4 — data kelompok: rumus Tb), lalu kurangkan.

Contoh tanpa outlier

Data 8, 9, 10, 11, 12, 13, 14, 18 (n = 8).
Q1 = 9,25; Q3 = 13,75 (letak 2,25 dan 6,75).
H = 13,75 − 9,25 = 4,5; Qd = 2,25.
J = 18 − 8 = 10.

Tambahkan outlier 40

Data menjadi 8, 9, 10, 11, 12, 13, 14, 18, 40 (n = 9).
Q1 = 9,5; Q3 = 16 → H = 6,5 (naik ±44%).
J = 40 − 8 = 32 (melonjak 220%!).
Kesimpulan: H jauh lebih kebal outlier daripada J.

Boxplot (pengayaan). Boxplot meringkas data menjadi 5 angka: Min, Q1, Me, Q3, Maks — kotaknya tepat sepanjang H. Pagar outlier: Q1 − 1,5×H dan Q3 + 1,5×H; titik data di luar pagar digambar terpisah sebagai outlier. Lab di bawah menggambarnya otomatis dari datamu.
Dua jebakan H & Qd: (1) Hubungan H = 2×Qd sering ditanya bolak-balik — diberi Qd, kalikan 2 untuk H. (2) H = 0 tidak berarti semua data sama: data 1, 3, 3, 3, 3, 3, 9 punya Q1 = Q3 = 3 sehingga H = 0, padahal ujungnya 1 dan 9 — artinya 50% data tengah bernilai sama.

Rangkuman & Strategi TKA

Kartu rumus inti, peta ekuivalensi antar-kuantil, dan lima strategi menaklukkan soal HOTS kuantil & jangkauan.

Kartu Rumus — Data Tunggal

Letak kuartil: Qi = i(n+1) : 4
Letak desil: Di = i(n+1) : 10
Letak persentil: Pi = i(n+1) : 100
Letak bulat → ambil datanya; pecahan → interpolasi xk + t(xk+1 − xk).
Jangkauan: J = maks − min (urutkan dulu!).

Kartu Rumus — Data Kelompok

Qi = Tb + ((i·n:4 − F) : f) × c
Di = Tb + ((i·n:10 − F) : f) × c
Pi = Tb + ((i·n:100 − F) : f) × c
Kelas kuantil: F < pos ≤ F + f lewat kumulatif.
J = tepi atas kelas akhir − tepi bawah kelas awal.

Peta Ekuivalensi Antar-Kuantil

P25 = Q1 · P50 = Q2 = D5 = median · P75 = Q3
P10 = D1 · P20 = D2 · P30 = D3 · P90 = D9
Dk = P10k dan Qk = P25k.
Sebaran: H = Q3 − Q1 = 2·Qd; jangkauan antardesil = D9 − D1 = P90 − P10.

Jebakan yang Harus Kamu Waspadai

Lupa mengurutkan data tunggal.
Letak memakai n, bukan (n+1) — ikuti konvensi sekolah.
Tb ditulis batas tulisan (51), bukan 50,5.
F dianggap kumulatif kelas kuantil, bukan sebelumnya.
Lupa × c; c dihitung 9 untuk kelas 41–50.
Soal "10% teratas" tak diterjemahkan ke D9/P90.

Lima strategi soal HOTS:
  • Kenali jenis datanya dulu. Daftar nilai = data tunggal (letak i(n+1):d); tabel kelas = data kelompok (pos i·n:d + interpolasi Tb). Mekanismenya beda — jangan tertukar.
  • Urutkan, lalu baru hitung. Seluruh kuantil hanya bermakna pada data terurut; cek ulang urutan sebelum mencari letak.
  • Tulis anatomi variabel satu per satu. Untuk data kelompok: pos, kelas kuantil, Tb, F, f, c — baru substitusi. Kesalahan paling umum adalah salah mengambil kelas atau F.
  • Terjemahkan kalimat cerita ke kuantil. "25% teratas" → Q3; "10% terbawah" → D1; "60% ke bawah" → P60; "top 1%" → P99. Setelah diterjemahkan, sisanya mesin hitung biasa.
  • Manfaatkan sifat transformasi & ekuivalensi. y = b·x + a menggeser semua ukuran letak dan melipatgandakan semua jangkauan dengan b; Q2 = D5 = P50 = median menjadi kunci cek cepat banyak soal.
